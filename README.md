PASS-Echo-PILOT: Программный комплекс для отбора, рандомизации и ведения пациентов с подозрением на ИБС
📌 Назначение
Комплекс предназначен для:

Оценки вероятности обструктивной ИБС по модели Risk Factor-weighted Clinical Likelihood (2024)
Отбора пациентов по критериям исследования PASS-Echo-PILOT
Рандомизации подходящих пациентов в две группы: стандартную и персонализированную
Формирования электронных карт пациентов (eCRF) с возможностью прикрепления файлов
Хранения и управления журналом пациентов с полной историей распределений
🧩 Состав комплекса
1. Калькулятор отбора пациентов (v2.2)
Рассчитывает риск ИБС на основе клинических данных
Проверяет соответствие критериям включения/исключения
Генерирует уникальный ID пациента
Экспортирует данные в JSON для передачи в рандомизатор
2. Рандомизатор с журналом (v2.6)
Принимает JSON-файлы из калькулятора
Автоматически распределяет пациентов в группы с учётом лимита (50/50)
Сохраняет полную историю распределений в локальном журнале
Поддерживает экспорт/импорт всего журнала
Обеспечивает обратную совместимость с данными из калькулятора стресс-ЭхоКГ
3. ESC Калькулятор Риска ИБС (vDS2.7.6)
Расширенная версия с рекомендациями по выбору метода стресс-ЭхоКГ (аденозин, физнагрузка, добутамин)
Поддерживает импорт данных из рандомизатора
Включает анализ противопоказаний и показаний к стресс-тестам
Формирует файлы рекомендаций по типу теста
4. eCRF-creator (v2.3)
Создаёт структурированную электронную карту пациента
Поддерживает прикрепление любых файлов (PDF, изображения и др.)
Экспортирует данные в HTML (с вложениями), TXT, Excel
Импортирует данные из JSON-файлов калькуляторов
Ведёт собственный журнал пациентов с поиском и редактированием
🔗 Рабочий процесс
Заполнить данные → Калькулятор отбора пациентов
Экспортировать JSON → загрузить в Рандомизатор
Выполнить рандомизацию → сохранить в журнал
При необходимости — загрузить распределённого пациента в ESC Калькулятор для назначения стресс-теста
Создать полную карту в eCRF-creator, прикрепить результаты исследований
💾 Хранение данных
Все журналы хранятся локально в браузере (localStorage)
Все экспортируемые файлы — в формате JSON / HTML / TXT / CSV
Полная совместимость между модулями через стандартизированные JSON-структуры
